Settings

Free to get at aistudio.google.com (Get API key). Stored only in this browser (localStorage). Used to call Gemini's vision API directly from your device to auto-detect garment type/color/tags. Leave blank to tag everything manually.

Backup & restore

Everything (photos, tags, outfits, wear history) is stored only in this browser. Clearing browser data, switching devices, or an app reset would lose it all — export a backup file regularly, especially before switching phones or browsers.
